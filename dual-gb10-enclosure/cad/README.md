# Dual GB10 R2.1 CAD

`generate_r2.py` 是当前权威 CAD 生成器，技术栈为 Python、Build123d/OpenCascade、Matplotlib 和 NumPy。装配坐标为 X 左右、Y 前后、Z 上下；STL 在导出前旋转到推荐打印方向并归一化到热床原点。

## 打印件

| 编号 | 零件 | 推荐方向 |
| --- | --- | --- |
| R2-101 | 一体式 U 型罩 | 外顶面朝下，8-10 mm brim |
| R2-102 | 滑入底板 | 底面平放 |
| R2-103 | 140 mm 前面板 | 外前表面朝下 |
| R2-104 | 60 mm 全周背框 | 外后表面朝下 |
| R2-105/106 | 左/右显示仓 | 外显示面朝下 |
| R2-107/108 | 左/右侧封片 | 外表面朝下 |

主结构使用不透明标准 PETG 或经配合规验证的 Tough PETG。导轨、舌边、挂钩和卡扣不得使用 Silk、碳纤填充、夜光、木粉或透明 PETG。

## 自动验证

```bash
uv run python -m unittest cad/test_generate_r2.py -v
```

测试覆盖：

- 8 个打印件均为单一有效实体且适配 `180 x 180 x 180 mm`；
- 两台 GB10、两只风扇和装配零件静态碰撞为零；
- 底板上下移动会被双向导轨阻挡；
- 前后面板向外移动会被下卡扣止回肩阻挡；
- 显示 T 键可走完整 `7 mm` 路径，锁定位置阻止外拔，释放卡扣后才可上移；
- 底板导向筋、后挡条与四个卡扣槽无相交；
- 每件热床接触面积至少 `100 mm2`，离床向下水平面总量不超过 `25 mm2`；
- STL 无退化三角形和非流形边。

布尔相交检查采用 fail-closed：OpenCascade 布尔失败会直接使测试或生成失败，不会被当作零碰撞。

## 先打印配合规

交付包的 `05_FIT_GAUGES` 包含双机、两种风扇、格栅、圆角、显示窗口、三档导轨间隙、前后卡扣和显示锁止接口。配合规直接复用生产参数和几何函数。实测后修改 `Params` 并重新生成，禁止整体缩放 STL。
