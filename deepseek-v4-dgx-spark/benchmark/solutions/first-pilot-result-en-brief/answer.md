This first Claude Code pilot used version 2.1.207 to compare the online deepseek-v4-flash route with the private deepseek-v4-flash-0731 route. Each route passed 3/4 hidden graders. The recorded elapsed times were 571.060 seconds for the online route and 417.190 seconds for the private route. Those timings are useful operational observations, but they should be read beside an important accounting difference: provider token, cache, and cost reporting is not identical across the two routes. The tasks, prompts, sandbox policy, and time limit were held fixed for this calibration. The evidence also records the resulting edits and grader outcomes so that another evaluator can inspect the same bounded exercise. Still, the run was only one repetition. It therefore does not establish an efficiency conclusion or statistical superiority for either route. The result is a reproducible snapshot for further controlled investigation, not a declaration that one treatment is an overall winner. Additional repetitions would need the same frozen corpus, Claude Code version, time limit, provider identity checks, and sandbox controls before any broader performance interpretation could be made. The two elapsed values should remain supporting telemetry rather than a replacement for repeated, comparable measurements.
