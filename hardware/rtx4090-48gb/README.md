# NVIDIA RTX 4090 48 GB

These records refer to a 48 GB configuration reported by `nvidia-smi`. They do
not imply that a standard 24 GB RTX 4090 can run the same profiles. Qwen3.6 and
Qwen3.8 recipes cover Ollama, vLLM, and llama.cpp with different contexts,
parallelism, quantization, and evidence maturity.

```bash
./lab list | grep rtx4090-48gb
```
