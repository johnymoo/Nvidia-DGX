性能差异的四个账本

混合因素必须分开记
账本TensorFold 做了什么vLLM 对应路径影响
Q4 字节EXL3/q4-MSE non-expert，EXL3 kernel 直接把 trellis tile 喂给 MMA。NVFP4 mixed，部分 non-expert 保留更高精度。这是最大混杂变量之一。
GRAPH launch固定 verify rows、固定 buffer、CUDA graph replay。通用 scheduler + block table + graph dispatcher。decode 每 token 的空隙更小。
DRAFT 猜测DFlash2 自适应深度，snapshot / ring cache 可回放。MTP/rejection sampler 需要重新汇合。多流下差距会被放大。
ROCE 汇合按 family 固定跨 rank 的小消息和 reduce 路径。通用分布式执行和 batch 形状。同步与元数据开销更容易显形。
03 / PHYSICAL CEILING

GB10 的墙在哪里？

当 GPU 利用率已在 94–96%，下一步不是无限堆 kernel，而是判断剩余带宽、显存和 drafter 预算。

有效内存带宽 · GB/s

每颗 GB10 / 每个 rank
273 GB/s 是单颗 GB10 的 LPDDR5X 理论值，TP=2 后每个 rank 仍主要读本地分片，不能简单相加成 546 GB/s；跨机 partial/all-gather 还要经过 CX7。纯 kernel 还剩约 5–15%；单流端到端约有 10–25% 的整理空间。更好的 drafter 在特定 workload 上可能再贡献约 10–20%，但 1M context 只剩约 5–7 GiB 余量。

下一轮实验的旋钮

按风险排序
prefill kernel overlap30–60% 局部空间
decode kernel / memory coalesce5–15%
drafter 接受率10–20%
判断：GB10 不是没有空间，而是空间已经从“换一个 runtime”转向“把剩余字节、同步和预测接受率榨干”。
