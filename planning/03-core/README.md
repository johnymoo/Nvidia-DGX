# Core Runbooks

This directory will hold the verified deployment contract and operator
runbooks. It is intentionally empty until the two-node service has passed live
acceptance.

Required final artifacts:

- architecture and host/network table;
- exact model, image, source revision, and immutable digests;
- start, status, smoke, benchmark, stop, and rollback commands;
- expected logs and failure signatures;
- dated acceptance evidence from both ranks and the API endpoint.
