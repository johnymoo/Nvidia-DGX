# Legacy Benchmark Evidence

Legacy projects retain their original schemas, metric definitions, workload
identities, values, and reports. They are useful Reference evidence but do not
automatically satisfy an active canonical suite.

- [Qwen and DeepSeek cross-model benchmark](qwen-deepseek-cross-model/)

Do not rewrite old TPS or TTFT fields into canonical definitions. A new
canonical result must name its suite version, receipt, workload, cache state,
concurrency, and all required metrics explicitly.
